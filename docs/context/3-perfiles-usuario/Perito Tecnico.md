## 6. Preguntas de Seguimiento Prioritarias
1. Último peritaje: desglosa horas — investigación web / visita / gabinete / cálculo.
2. ¿Qué páginas y portales abres siempre? ¿Cuántas pestañas?
3. ¿Cómo reconstruyes historia satélite año por año? ¿Cuánto demora?
4. ¿Cuántos peritajes activos simultáneos? ¿Cómo retomas uno pausado?
5. Si automatizaras solo la investigación documental, ¿cuánto pagarías? ¿Y el informe completo?
