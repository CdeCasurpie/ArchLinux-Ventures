# Entrevista de Validación - Israel (Resumen de Entrevistador)
**Nota:** Esta transcripción es un **debrief del entrevistador**, no la entrevista directa. Roles reportados: Inspector de Obra + Proyectista.

## 1. Perfil: Inspector de Obra (Outlier de Eficiencia)
- **Entregable completo en 4 horas:** 3 horas de visita + **1 hora** para el informe.
- Toma pocas fotos; usa aproximadamente **la mitad** de las que toma (elige el mejor ángulo, no por error).
- Organizar fotos le resulta **muy fácil**.
- Usa formato del **Ministerio de Vivienda**: a veces lo imprime, llena checks de cumplimiento/no cumplimiento y redacta.

## 2. Perfil: Proyectista
- **Mayor dolor:** Gestión y **coordinación de horarios** con ingenieros y especialistas.
- Equipos mixtos (virtuales y presenciales) → fricción de agenda, no coinciden horarios.
- Este dolor es de **coordinación de proyecto**, no de documentación administrativa.

## 3. Implicaciones para ArchVentures
| Aspecto | Insight |
|:---|:---|
| Segmentación | Israel es un **outlier** — 1h de informe vs. 4-5h de Vicky Rosales |
| Riesgo de sesgo | No todos los inspectores sufren el mismo dolor; el problema puede ser de **segmento o experiencia** |
| Problema P6 | **Débilmente validado** en este perfil eficiente |
| Nuevo dolor | Coordinación multi-especialidad (proyectista) — fuera del MVP actual pero relevante |
| Formato estándar | Uso de formatos ministeriales con checks → oportunidad de **plantillas inteligentes** |

## Conclusión
Israel demuestra que inspectores **altamente eficientes** existen y no sienten el dolor de reportes. Esto refuerza la necesidad de definir el ICP como inspectores que **sí pierden horas** (ej. Vicky, inspectores municipales sin asistente). El dolor de coordinación abre una línea secundaria para proyectistas.
