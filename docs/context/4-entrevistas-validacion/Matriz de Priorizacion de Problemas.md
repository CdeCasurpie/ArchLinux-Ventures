## Criterios de Puntuación
1. **Tamaño del problema (1-10):** ¿Qué tan grande es el problema que quieres resolver? (1=pequeño, 10=muy grande).
2. **Founder Market Fit (1-10):** ¿Qué tanto FMF tenemos? (1=poco, 10=mucho).
3. **Facilidad de Validación (1-10):** ¿Qué tan fácil será validar este problema? (1=muy difícil, 10=muy sencillo).
4. **Urgencia (1-10):** ¿Qué tan urgente es el problema? (1=un pequeño inconveniente, 10=un problema incendio).
