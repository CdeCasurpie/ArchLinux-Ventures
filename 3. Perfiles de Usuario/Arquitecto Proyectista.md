# Arquitecto Proyectista

## 1. Contexto del Rol
El profesional enfocado en el diseño arquitectónico, el modelado 3D y la elaboración de la documentación técnica.

## 2. Conexión con los Problemas
- Son las víctimas directas del [[Retrabajo CAD-SketchUp]].
- Sufren el problema del [[Calco Manual de Planos]] cuando inician un proyecto de remodelación y solo les dan PDFs.

## 3. Supuestos Críticos a Validar
- **Factible (Hecho):** Exportar de SketchUp a AutoCAD genera líneas dobles que deben limpiarse con `OVERKILL`.
- **Supuesto (Por comprobar en entrevistas):** Este proceso les duele lo suficiente como para pagar mensualmente por un software que les exporte cortes vectoriales limpios sin usar LayOut.
