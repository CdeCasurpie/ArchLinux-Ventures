## 5. Supuestos Críticos
- **Validado:** Export SketchUp→CAD genera líneas dobles (OVERKILL).
- **Validado:** Expediente municipal = mayor bloque de tiempo (3/5).
- **Validado:** Cambios post-aprobación consumen día completo (2/5).
- **Nuevo — Validado:** No siguen pipeline propio con múltiples proyectos (César).
- **Refutado parcial:** Pagarían por export limpio — senior ya tiene workarounds.

## 6. Preguntas de Seguimiento Prioritarias
**Gestión (Capa 2 — prioridad):**
1. Lista tus proyectos activos: ¿en qué etapa está cada uno **ahora**?
2. ¿Cómo retomas un proyecto después de 2 semanas sin tocarlo?
3. ¿Algún sistema personal (Excel, cuaderno, app) para no perderse?
4. Si tuvieras un tablero visual de etapas por proyecto, ¿cuánto pagarías?

**Expediente (Capa 1):**
5. Desglosa las 40h de expediente: planos / FUE / memorias / firmas.
6. ¿Qué delegas al asistente y qué nunca delegas?
